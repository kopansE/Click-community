# Stream Chat Integration for Click

## Architecture
- Stream Chat handles ALL messaging (DMs + event group chats)
- Supabase does NOT store messages — Stream is the source of truth
- Server generates Stream user tokens using STREAM_API_SECRET
- Client uses NEXT_PUBLIC_STREAM_API_KEY

## Server-Side Setup (src/lib/stream/)
```typescript
import { StreamChat } from 'stream-chat';

const serverClient = StreamChat.getInstance(
  process.env.NEXT_PUBLIC_STREAM_API_KEY!,
  process.env.STREAM_API_SECRET!
);

// Generate user token
export function generateStreamToken(userId: string) {
  return serverClient.createToken(userId);
}

// Create DM channel
export async function createDMChannel(userAId: string, userBId: string, icebreaker?: string) {
  const channel = serverClient.channel('messaging', {
    members: [userAId, userBId],
    created_by_id: userAId,
  });
  await channel.create();
  if (icebreaker) {
    await channel.sendMessage({
      text: icebreaker,
      user_id: userAId,
      custom: { isIcebreaker: true },
    });
  }
  return channel;
}

// Create event group chat
export async function createEventChannel(eventId: string, eventName: string, memberIds: string[]) {
  const channel = serverClient.channel('messaging', `event-${eventId}`, {
    name: eventName,
    members: memberIds,
  });
  await channel.create();
  return channel;
}
```

## Channel Naming Convention
- DMs: auto-generated by Stream (no custom ID needed)
- Event chats: `event-{eventId}`

## Icebreaker Messages
- Set `custom.isIcebreaker: true` on the message
- Render with special styling (primary-50 bg, "Icebreaker" label)

## Blocking
When a user blocks another:
1. Call Stream API to hide the channel for both users
2. Add to blocked_users in Supabase
3. Stream will handle message delivery prevention

## Cleanup
- Archive event chat channels 7 days after event ends (cron job)
